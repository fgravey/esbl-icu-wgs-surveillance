# Input data

The pipeline expects the following files in this `data/` folder. Because the
cohort contains protected patient information (French GDPR), these files are
NOT included in the repository. They are available from the corresponding
author upon reasonable academic request.

## Expected input files

| File | Role | Used by |
|------|------|---------|
| `BLSE_cohort_curated.tsv` | Raw curated isolate-level database (one row per ESBL-E isolate, with clinical metadata, ward, sampling date, MLST ST, cgSNP cluster, AMR markers, screening chronology). Tab-separated. | Script 01 |
| `JH_admission_rea_2019_2023.xlsx` | Yearly ICU admission denominators per unit (sheets and labels in French, e.g. "Nb journees HC"), used for incidence rates and IRR in Table 2 / Figure 2. | Script 07 |
| `article-blse-plasmidfinder.csv` | PlasmidFinder replicon profiling export (semicolon-separated, 6 metadata header lines skipped on read). | Script 13 |

## Files generated by the pipeline (written back into `data/`)

- `BLSE_cohort_curated_clean.tsv` — de-duplicated cohort (output of script 01)
- `BLSE_cohort_final_with_transmissions.tsv` — final analytical cohort with
  genomic transmission linkage flags (output of script 02; main input of all
  downstream scripts)

Note: the source database uses some French free-text labels (screening
chronology "avant"/"apres", anatomical infection-site keywords). These literal
strings are matched inside the scripts and must be kept as-is for
reproducibility.
